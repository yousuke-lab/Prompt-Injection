研究背景および⽬的  
異なるモデルのLLMに外部ツールを用いてガードレールを実装した上での日本語によるDirect Injectionを研究しています。
その目的としてLLMGuardやGuardrails AIといったスタンダードなツールは英語での攻撃を想定して作られているため英語による
攻撃は検知できますが、日本語で攻撃が行われた場合に脆弱となる恐れは依然として残っています。  
  実験⽅法もしくは研究⼿法  
そのためLLMGuardやGuardrails AIといったツール用いてInput Guard 、Prompt Hardening 、O
utput Validationの三層防御を実装し、その突破率、偽陽性率などの項目で英語によるプロンプトインジェクションと日本語によるプ
ロンプトインジェクションで比較し、適切な運用方法を分析しています。  
  実験結果および成果  
現在は日本語による効果的な攻撃データセットを作るのに時間をかけていて、まだまだ研究途中です。
  考察および今後の展望  
今後は日本語の攻撃プロンプトが完成し次第、本格的に英語との比較をしていき、時間が許す限り日本語の方言や英語との混合を試みたり、更に工夫し
ていきます。
